# PDF Generation Instructions

Convert the Markdown report to PDF:

## Option 1: Pandoc (Recommended)
```bash
# Install Pandoc: https://pandoc.org/installing.html
pandoc AI-Capacity-Planning-Report.md -o AI-Capacity-Planning-Report.pdf --pdf-engine=pdflatex
```

## Option 2: VSCode
1. Install Markdown PDF extension
2. Right-click `AI-Capacity-Planning-Report.md` → \"Markdown PDF: Export (pdf)\"

## Option 3: Online
- Paste Markdown into [Markdown to PDF](https://www.markdowntopdf.com/)

**Result**: Professional PDF ready for stakeholder sharing.
